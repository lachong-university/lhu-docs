**Import dữ liệu từ file mẫu excel**

* **Bước 1:** Chọn danh mục dự trù kinh phí cần thêm → Click **Thêm dự trù** ![](/du-tru-kinh-phi-lhu/2-2-them-hieu-chinh-xoa-du-tru-kinh-phi-08.png)
  → Chọn **Import Excel** ![](/du-tru-kinh-phi-lhu/2-3-import-du-lieu-tu-file-mau-excel-23.png)→ Chọn **File Excel mẫu** ![](/du-tru-kinh-phi-lhu/2-3-import-du-lieu-tu-file-mau-excel-24.png)

  ![](/du-tru-kinh-phi-lhu/2-3-import-du-lieu-tu-file-mau-excel-25.png)
* **Bước 2:** Nhập đầy đủ thông tin file excel mẫu **dataFP.xlsx**
  + STT, NoiDungDuTru, SoLuong, DonViTinh, DonGia, ThanhTien, MoTaChiTiet, ThangThucHien, ThangQuyetToan, LyDoMua, ...\ **Lưu ý:** \ → Tháng thực hiện, tháng quyết toán nhập từ số 1 đến 12. \ → Nếu quyết toán theo năm nhập số 100.\ → **KHÔNG** định dạng phân cách phần ngàn cho những cột có giá trị **kiểu SỐ**.\ → **STT phân biệt, KHÔNG trùng nhau** + phân biệt với những giá trị đã thêm trước đó.

  ![](/du-tru-kinh-phi-lhu/2-3-import-du-lieu-tu-file-mau-excel-26.png)
* **Bước 3:** Sau khi hoàn thành bước 2 nhập liệu → Chọn **Mở DS** ![](/du-tru-kinh-phi-lhu/2-3-import-du-lieu-tu-file-mau-excel-27.png)→ Chọn **Thêm Dự Trù** ![](/du-tru-kinh-phi-lhu/2-3-import-du-lieu-tu-file-mau-excel-28.png)để load file excel mẫu lên hệ thống (file dataFP.xlsx đã nhập liệu) → Chọn **Thêm dự trù** để import → Chọn **OK** để xác nhận.

  ![](/du-tru-kinh-phi-lhu/2-3-import-du-lieu-tu-file-mau-excel-29.png)
