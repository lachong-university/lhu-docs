Mọi hàm dưới đây là **global**, gọi được từ `EXE`, từ khối `<script>`, từ `attr` của control và
từ `uc-*.vue`. Không cần import.

## Thư viện đã bundled — đừng thêm CDN

Có sẵn trên mọi trang FUI. Thêm lại từ CDN chỉ làm trang nặng thêm.

| Thư viện | Biến global |
|---|---|
| jQuery | `$` · `jQuery` |
| Lodash | `_` |
| Moment | `moment` |
| Numeral | `numeral` |
| Vuetify | `Vuetify` |
| vue-toast | qua `Vue.$toast` |
| jquery-confirm | qua `confirm()` |

## Biến global

| Biến | Nội dung |
|---|---|
| `vueData` | Toàn bộ state của trang. Cũng chính là data root của instance Vue |
| `vm` | Instance Vue — dùng `vm.formvalidate()` để validate form |
| `$isMobile` · `$isPhone` · `$isApple` | Nhận diện thiết bị qua user-agent |
| `$awt` | Bearer token hiện tại |

## Ví dụ dùng thật

<Tabs items={['Gọi API trong uc-*.vue', 'Xuất Excel', 'Xác nhận rồi mới làm']}>

<Tab value="Gọi API trong uc-*.vue">
```js
methods: {
  taiDanhSach: function () {
    var self = this;
    ajaxCALL('/api/nhanvien/list', { PhongBanID: this.phongBanID },
      function (res) { self.items = res.data; },
      function (err) { showMessage({ type: 'red', title: 'Lỗi tải dữ liệu' }); }
    );
  }
}
```
Không dùng `fetch()` — nó không mang theo bearer token và cấu hình CORS của FUI.
</Tab>

<Tab value="Xuất Excel">
```json
{
  "EXE": "jsonToExcel({ data: dsNhanVien, filename: 'nhan-vien.xlsx', worksheet: 'Danh sách' })"
}
```
Riêng `f-table` đã có sẵn nút Excel — chỉ cần `":excel": true`.
</Tab>

<Tab value="Xác nhận rồi mới làm">
```json
{
  "EXE": "confirm({ title: 'Xoá toàn bộ?', action: function(){ CALL(vueData.xoaTatCa) } })"
}
```
Thường thì dùng khoá `CONFIRM` của action gọn hơn — chỉ xuống mức hàm khi cần logic đặc biệt.
</Tab>

</Tabs>
