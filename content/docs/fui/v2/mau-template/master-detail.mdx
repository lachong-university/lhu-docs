Bảng danh sách chiếm cột trái, chi tiết của dòng đang chọn hiện ở cột phải. Đây là mẫu hay dùng
cho dữ liệu có nhiều field mà mở dialog thì bất tiện.

Cơ chế: `f-table` phát event `click:row`, action lưu dòng vào state, panel phải hiện ra nhờ
`v-if`.

## Cơ chế chọn dòng

`f-table` phát `click:row` kèm object dòng. Bắt bằng `v-on:` và truyền `$event` vào action:

```json
"v-on:click:row": "CALL(vueData.chonDonHang, { $row: $event })"
```

Action nhận `$row` rồi gán vào state và tải chi tiết:

```json
"chonDonHang": [
  { "donHangChon": "$row" },
  { "CALL": "apiChiTiet" }
]
```

<Callout>
Hai bước tách rời nhau là cố ý: bước một gán state (Vue vẽ lại panel ngay), bước hai mới gọi API.
Người dùng thấy phản hồi tức thì thay vì chờ mạng.
</Callout>

## Đánh dấu dòng đang chọn

```json
":item-class": "item => item.ID == (vueData.donHangChon && vueData.donHangChon.ID) ? 'primary lighten-5' : ''"
```

`:item-class` nhận một hàm dạng chuỗi. Nhớ kiểm tra `donHangChon` khác `null` trước khi đọc `.ID`
— lúc trang vừa load nó còn rỗng.

## Panel rỗng

Hai `v-card` loại trừ nhau bằng `v-if` trên `col`:

```json
{ "el": "v-card", "w": 5, "col": { "v-if": "vueData.donHangChon" },  ... }
{ "el": "v-card", "w": 5, "col": { "v-if": "!vueData.donHangChon" }, ... }
```

Đặt điều kiện ở `col` chứ không ở `attr` — như vậy ẩn cả ô lưới, cột trái không bị lệch.

## Những chỗ dễ sai

<Callout type="warn">
**`v-model` trong panel phải trỏ vào `donHangChon.Field`**, tức là sửa thẳng object trong mảng
`dsDonHang`. Bảng bên trái sẽ cập nhật theo ngay khi gõ — tiện, nhưng nghĩa là **người dùng thấy
thay đổi trước khi bấm Lưu**.

Không muốn vậy thì clone object lúc chọn:
`{ "donHangChon": "_.cloneDeep($row)" }`
</Callout>

<Callout type="warn">
Trong `controls`, biểu thức `v-if` chạy ở scope Vue nên **cần prefix `vueData.`**. Còn trong
`data[]`, `IF`/`EXE` chạy qua lodash template nên **không cần**. Cùng một biến, hai cách viết.
</Callout>

<Tabs items={['Chi tiết mở cửa sổ riêng', 'Master–detail dọc']}>

<Tab value="Chi tiết mở cửa sổ riêng">
Chi tiết quá phức tạp thì tách thành module riêng và mở bằng `openWindow`:

```json
"chonDonHang": [
  { "donHangChon": "$row" },
  { "EXE": "openWindow({ id: 'winChiTiet', title: 'Chi tiết đơn hàng', url: '/ex/donhang-chitiet?id=' + $row.ID, onclose: { CALL: 'apiDanhSach' } })" }
]
```

Cửa sổ con ghi ngược về cha bằng key `#PARENT`:

```json
{ "#PARENT.dsDonHang": "dsDonHang" }
```
</Tab>

<Tab value="Master–detail dọc">
Màn hình hẹp thì xếp dọc — bảng trên, chi tiết dưới:

```json
{ "prop": "row", "cols": [ { "el": "f-table", "w": 12, "attr": { } } ] },
{ "prop": { "v-if": "vueData.donHangChon" },
  "cols": [ { "el": "v-card", "w": 12, "attr": { } } ] }
```

Ở đây `v-if` đặt trên `prop` của cả hàng — ẩn nguyên hàng chi tiết khi chưa chọn gì.
</Tab>
