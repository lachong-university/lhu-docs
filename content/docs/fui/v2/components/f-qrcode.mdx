`f-qrcode` render một mã QR từ chuỗi `value` — dùng cho link chia sẻ, mã checkin, mã tra cứu.

## Import bắt buộc

<Callout type="error">
Thiếu import thì component không tồn tại.

```text
/include/qrcode/qrcode.min.js
```
</Callout>

## Cách dùng

<Tabs items={['Tối giản (demo)', 'Kèm logo']}>

<Tab value="Tối giản (demo)">
```json
{
  "el": "f-qrcode",
  "w": "",
  "attr": { "v-model": "linkChiaSe", ":size": 200 }
}
```
</Tab>

<Tab value="Kèm logo">
```json
{
  "el": "f-qrcode",
  "w": "",
  "attr": {
    "v-model": "maCheckin",
    ":size": 240,
    "logo": "https://cdn.example.com/logo-small.png"
  }
}
```
</Tab>

</Tabs>

## Lỗi thường gặp

<Callout type="warn">
`value` rỗng thì không render gì — khai giá trị mặc định trong `data[]` hoặc bọc `v-if` để tránh
khoảng trống trước khi dữ liệu tải xong.
</Callout>

## Component liên quan

- `f-qrcode-reader` — chiều ngược lại, đọc mã QR bằng camera
