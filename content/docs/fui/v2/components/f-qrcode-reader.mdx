`f-qrcode-reader` mở một dialog dùng camera của thiết bị để quét mã QR — thường dùng cho
checkin, xác thực vé, tra cứu nhanh bằng mã in sẵn.

## Import bắt buộc

<Callout type="error">
Thiếu import thì component không tồn tại.

```text
/include/qrcode/qrcode-reader.min.js
```
</Callout>

**Event**: `input` (đóng dialog) · `update` (nội dung mã QR vừa đọc được)

## Cách dùng

```json
{
  "el": "f-qrcode-reader",
  "w": 12,
  "attr": {
    "v-model": "dlQuetMa",
    "label": "Quét mã checkin",
    "v-on:update": "CALL(vueData.xuLyMaQuet, { item: $event })"
  }
}
```

```json
{
  "xuLyMaQuet": {
    "API": "/api/checkin/xacnhan",
    "IN": { "MaVe": "item" },
    "CALLBACK": { "MESS": "Checkin thành công" }
  }
}
```

Mở dialog bằng cách gán `dlQuetMa = true`, thường từ một nút:

```json
{ "el": "f-button", "attr": {
    "label": "Quét mã", "icon-text": "mdi-qrcode-scan",
    ":checkvalid": false, ":action": { "dlQuetMa": true } } }
```

## Lỗi thường gặp

<Callout type="warn">
**Cần HTTPS.** Trình duyệt chỉ cấp quyền camera cho ngữ cảnh bảo mật (`https://` hoặc
`localhost`) — quét không hoạt động trên `http://` thường.
</Callout>

<Callout type="warn">
Người dùng từ chối quyền camera thì dialog vẫn mở nhưng không đọc được gì — nên có hướng dẫn dự
phòng (nhập mã tay) cho trường hợp này.
</Callout>
