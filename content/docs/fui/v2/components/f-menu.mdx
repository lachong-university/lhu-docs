Dùng `f-menu` thay `v-menu` + `v-btn` khi cần một nút mở ra danh sách hành động. Cấu hình gọn
hơn — mỗi mục chỉ là một object trong mảng `items`.

### Cấu trúc một phần tử `items`

| Khoá | Tác dụng |
|---|---|
| `text` | Nhãn hiển thị |
| `icon-text` | Icon bên trái |
| `color` | Màu icon |
| `action` | Object action FUI — chạy qua `runAction` khi bấm |
| `href` + `target` | Điều hướng như thẻ `<a>` — dùng thay `action` |
| `visible` | Ẩn/hiện mục. Mặc định `true` |

### Default FUI tự thêm

```json
{ "elevation": "1", ":depressed": true, "color": "primary" }
```

## Cách dùng

<Tabs items={['Tối giản', 'Đầy đủ (demo)']}>

<Tab value="Tối giản">
```json
{
  "el": "f-menu",
  "w": "",
  "attr": {
    "label": "Tác vụ",
    "icon-text": "mdi-dots-vertical",
    ":items": [
      { "text": "Xem chi tiết", "icon-text": "mdi-eye", "action": { "CALL": "vueData.xemChiTiet" } },
      { "text": "Xuất Excel",   "icon-text": "mdi-file-excel", "action": { "CALL": "vueData.xuatExcel" } }
    ]
  }
}
```
</Tab>

<Tab value="Đầy đủ (demo)">

  "w": "",

## Ẩn mục theo điều kiện

```json
{
  ":items": [
    { "text": "Duyệt",  "icon-text": "mdi-check",
      "visible": "vueData.user.SystemRight >= 9",
      "action": { "CALL": "apiDuyet" } },
    { "text": "Xoá",    "icon-text": "mdi-delete", "color": "error",
      "action": { "CONFIRM": "Xác nhận xoá?", "CALL": "apiXoa" } }
  ]
}
```

## Lỗi thường gặp

<Callout type="warn">
**Không khai `label`, hoặc để rỗng, thì nút chỉ hiện icon** (`icon-only`). Đây là hành vi có chủ
đích, không phải lỗi — hữu ích trong cột `t-menu` của `f-table` khi cần nút gọn.
</Callout>

## Component liên quan

- `t-menu` — cùng cơ chế, dùng trong `headers` của `f-table` để mở menu ngữ cảnh trên từng dòng
