`f-title` render một dòng tiêu đề nhỏ (`title`, màu `primary`) — dùng cho tiêu đề của từng khối
hoặc section, nhỏ hơn [`f-header`](/docs/fui/v2/components/f-header).

<TypeTable
  type={{
    label: {

      type: "String",
    },
  }}
/>

## Cách dùng

```json
{ "el": "f-title", "w": 12, "attr": { "label": "Thông tin liên hệ" } }
```

<Callout>
Đây là component xuất hiện nhiều nhất trong bộ demo của tài liệu này — mỗi trang component đều
dùng `f-title` làm tiêu đề khối.
</Callout>

## Component liên quan

- [`f-header`](/docs/fui/v2/components/f-header) — tiêu đề lớn hơn, dùng cho tiêu đề chính đầu trang
