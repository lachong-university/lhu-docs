`f-dialog` tự build một form bên trong modal từ mảng `controls` bạn truyền vào, kèm watcher cục
bộ và nút bấm cấu hình sẵn. Tiện cho form nhỏ, độc lập — không hợp cho CRUD một bảng.

<Callout type="warn">
**Không dùng `f-button` + `f-dialog` để mở form thêm mới cho bảng** — không ổn định trong FUI V2.
Dùng `ctrl-update` của [`f-table`](/docs/fui/v2/components/f-table)
(`:update-form` + `:update-api`) cho CRUD. `f-dialog` chỉ hợp cho form rất nhỏ, độc lập với bảng
nào — ví dụ hộp nhập một giá trị đơn, xác nhận có kèm input.
</Callout>

**Event**: `input` (đóng/mở) · `update:data-out` (phát instance khi mở) ·
`update:data` (phát `v_outData` khi bấm nút có `getoutdata: true`)

### Cấu trúc một phần tử `button`

| Khoá | Tác dụng |
|---|---|
| `label` | Chữ trên nút |
| `color` | Mặc định `primary` |
| `text` | `true` = dạng text button (mặc định) |
| `type` | Ví dụ `"submit"` |
| `:disabled` | Biểu thức Vue, vd `"!checkBoxValue"` |
| `v-if` | Ẩn/hiện nút, vd `"ModuleID==1"` |
| `icon-text` | Icon bên trái label |
| `checkvalid` | Validate form trước khi chạy `action` — không qua thì dừng |
| `getoutdata` | Đồng bộ field vào `v_outData` rồi phát `update:data` |
| `action` | Mảng action chạy khi bấm |

### Default FUI tự thêm

```json
{ ":outlined": true, ":dense": true }
```

## Cách dùng

<Tabs items={['Tối giản (demo)', 'Đầy đủ với watch']}>

<Tab value="Tối giản (demo)">
```json
{
  "el": "f-dialog",
  "attr": {
    "v-model": "dlNhapGhiChu",
    "title": "Nhập ghi chú",
    ":controls": [
      { "el": "v-textarea", "attr": { "v-model": "noiDung", "label": "Ghi chú", "rows": 3 } }
    ],
    ":button": [
      { "label": "Lưu", "type": "submit", "checkvalid": true,
        "action": [ { "MESS": "Đã lưu ghi chú" }, { "dlNhapGhiChu": false } ] },
      { "label": "Đóng", "action": [ { "dlNhapGhiChu": false } ] }
    ]
  }
}
```
</Tab>

<Tab value="Đầy đủ với watch">
```json
{
  "el": "f-dialog",
  "attr": {
    "v-model": "dlChonModule",
    ":data.sync": "dialogData",
    "title": "Chọn module",
    ":controls": [
      { "el": "v-select", "attr": {
          "v-model": "moduleID", "label": "Module",
          ":items": "vueData.dsModule", "item-text": "`ModuleName", "item-value": "`ModuleID" } }
    ],
    ":watch": {
      "moduleID": { "MESSBOX": "Đã chọn {{moduleID}}" }
    },
    ":button": [
      { "label": "Xác nhận", "type": "submit", "checkvalid": true, "getoutdata": true,
        "action": [ { "dlChonModule": false } ] },
      { "label": "Huỷ", "action": [ { "dlChonModule": false } ] }
    ]
  }
}
```

`getoutdata: true` phát `update:data` — bắt bằng `:data-out.sync` để nhận giá trị vừa chọn ở
component cha.
</Tab>

</Tabs>

## Lỗi thường gặp

<Callout type="warn">
**Biến bind trong `:controls` với `vueData.` phải đã khai trước trong `data[]`.** Vue không thiết
lập được reactivity cho biến chưa tồn tại lúc `data()` init. Field không có prefix `vueData.` thì
`f-dialog` tự tạo field cục bộ, không bị ràng buộc này.
</Callout>

<Callout type="warn">
**Template dựng tĩnh lúc khởi tạo** — đổi `controls` sau khi dialog đã mount một lần sẽ không
re-render. Cấu hình `controls` phải cố định, không dựng động theo state khác.
</Callout>

<Callout type="error">
**Không đặt `f-dialog` bên trong template của một `uc-*.vue`.** Nó chỉ hoạt động khi khai trực
tiếp trong `controls` của module JSON. Cần dialog trong component thì dựng `v-dialog` thủ công
— xem [cách viết component riêng](/docs/fui/v2/kien-truc/custom-component#dialog-trong-component).
</Callout>
