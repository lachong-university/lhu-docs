`f-echart` là lớp bọc mỏng quanh **Apache ECharts V5**. Prop `option` chính là ECharts option
nguyên bản, nên khi cần cấu hình gì cứ dùng thẳng kiến thức ECharts. FUI chỉ thêm: nạp theme,
vài shortcut trong `config`, bảng xem dữ liệu, và các event.

Dùng `f-echart` cho mọi loại biểu đồ. Component `f-chart` (Chart.js) là bản cũ.

## Import bắt buộc

<Callout type="error">
Thiếu import thì `<f-echart>` **không tồn tại** và vùng biểu đồ trắng trơn.

```text
1. /include/chart/echarts.min.js   ← ECharts core, phải chạy TRƯỚC
2. /include/chart/fechart.js       ← lớp bọc FUI, phải chạy SAU
```

Thứ tự do **`FileSort` quyết định**, không phải thứ tự bạn thêm hay phạm vi project/module.
`fechart.js` phụ thuộc biến global `echarts`, nên `FileSort` của nó phải **lớn hơn** — ví dụ
100 và 110.
</Callout>

### Thứ tự merge

`config` dựng phần nền → `option` ghi đè lên trên.

| Kiểu | Cách merge |
|---|---|
| Mảng (`series`, `color`, `xAxis`…) | **Thay thế** |
| Object thường | Deep merge |
| Giá trị đơn | Thay thế |

### Các khoá của `config`

| Khoá | Kiểu | Mặc định | Tác dụng |
|---|---|---|---|
| `height` | number \| string | `400` | Số = px; chuỗi = `'50vh'`… |
| `theme` | string \| null | `'fui'` | `'fui'` · `'shine'` · `'v5'`; `null` = không theme |
| `title` | string | | → `option.title.text` |
| `subtitle` | string | | → `option.title.subtext` |
| `titleLeft` | string | `'left'` | `left` · `center` · `right` |
| `color` | string[] | | Đổi bảng màu |
| `legend` | false \| Object | | `false` = ẩn |
| `tooltipFormat` | string | `'auto'` | `number` · `percent` · `currency` · `short` · `auto` |
| `dataView` | boolean | `false` | Hiện nút bảng xem dữ liệu |
| `toolbox` | boolean | `false` | Hiện toolbox (lưu ảnh + khôi phục) |
| `zoom` | boolean | | Bật dataZoom |
| `animation` | boolean | | `false` = tắt hiệu ứng |
| `refreshInterval` | number | | ms — tự làm mới |
| `backgroundColor` | string | `'transparent'` | Nền biểu đồ |

**Event**: `chart-click` · `drilldown` · `legend-change` · `rendered` · `finished`

## Quy ước hiển thị mặc định

Đúc kết từ các yêu cầu chỉnh sửa lặp đi lặp lại của người dùng thật. Áp dụng ngay từ đầu cho mọi
biểu đồ mới, trừ khi có yêu cầu khác:

<Steps>

<Step>
### Luôn hiện giá trị trên biểu đồ

Bar và line: `"label": { "show": true, "position": "top" }`.
Bar ngang thì dùng `"position": "right"`.
</Step>

<Step>
### Padding lưới

`"grid": { "left": 20, "right": 20, "containLabel": true }` — đừng để dư khoảng trắng hai bên.
</Step>

<Step>
### Số hiển thị đầy đủ

`1,500,000` chứ không rút gọn `1.5M`. Mặc định đã đúng — **đừng override** `tooltipFormat` trừ
khi được yêu cầu.
</Step>

<Step>
### Pie đừng để labelLine dài

Nhãn ngắn gọn, hoặc dồn thông tin về legend và tooltip.
</Step>

<Step>
### Đừng tự dựng nút "Xem dữ liệu"

Dùng `"dataView": true` có sẵn.
</Step>

</Steps>

## Bảng xem dữ liệu

`config.dataView: true` thêm icon bảng ở góc trên phải. Bấm vào hiện overlay bảng dữ liệu.

Dữ liệu được **tự trích từ `option`**, không cần truyền riêng:

1. Ưu tiên `option.dataset.source`
2. Không có thì lấy `option.series[].data` cùng `xAxis.data` / `yAxis.data`
3. Không tìm được dữ liệu phù hợp thì nút tự ẩn

Bỏ `dataView` khi option không có mảng series rõ ràng — gauge một giá trị, sankey node/link, tree
phân cấp.

<Callout>
Đây là **overlay Vue riêng của FUI**, không phải DataView của ECharts toolbox. `config.toolbox:
true` chỉ thêm lưu ảnh và khôi phục.
</Callout>

## Nối với dữ liệu từ API

Biểu đồ hay phải dựng lại sau khi API trả về. Dựng `option` trong khối `<script>` rồi gọi bằng
`FUN`:

```vue
<script>
function buildChartOption(input) {
  return {
    grid: { left: 20, right: 20, containLabel: true },
    xAxis: { type: 'category', data: _.map(input.rows, 'Thang') },
    yAxis: { type: 'value' },
    series: [{
      type: 'bar',
      data: _.map(input.rows, 'DoanhThu'),
      label: { show: true, position: 'top' }
    }]
  };
}
</script>
```

```json
{
  "apiDoanhThu": {
    "API": "/api/baocao/doanhthu",
    "IN":  { "Nam": "filter.nam" },
    "OUT": "dsDoanhThu",
    "CALLBACK": {
      "FUN": "buildChartOption",
      "IN":  { "rows": "dsDoanhThu" },
      "OUT": "chartOption"
    }
  }
}
```

## Lỗi thường gặp

<Callout type="warn">
**Trang trắng, console báo unknown element `f-echart`** → thiếu import, hoặc `fechart.js` có
`FileSort` nhỏ hơn `echarts.min.js` nên chạy trước lúc biến `echarts` chưa tồn tại.
</Callout>

<Callout type="warn">
**Mảng bị thay thế chứ không merge.** Khai `series` trong `config` rồi lại khai trong `option`
thì bản trong `option` thắng hoàn toàn. Để dữ liệu ở `option`, để phần trình bày ở `config`.
</Callout>

<Callout>
Biểu đồ không hiện mà không có lỗi thì kiểm tra `config.height` — chiều cao `0` cho ra canvas
rỗng. Mặc định là `400`.
</Callout>
