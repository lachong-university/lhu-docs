`f-excel-reader` đọc sheet đầu tiên của một file Excel/CSV và phát ra mảng object — toàn bộ xử
lý diễn ra ở trình duyệt, không gọi API upload. Thư viện XLSX được tự nạp khi cần (lazy-load).

## Cách dùng

<Tabs items={['Tối giản (demo)', 'Có action sau khi đọc']}>

<Tab value="Tối giản (demo)">
```json
{
  "el": "f-excel-reader",
  "w": "",
  "attr": {
    "label": "Nhập từ Excel",
    "icon-text": "mdi-microsoft-excel",
    "v-model": "dsExcelDoc"
  }
}
```

Kết quả bind vào `dsExcelDoc` — thử đưa vào `f-table` để xem ngay:

```json
{ "el": "f-table", "w": 12, "attr": { "label": "Xem trước", ":items": "dsExcelDoc" } }
```
</Tab>

<Tab value="Có action sau khi đọc">
```json
{
  "el": "f-excel-reader",
  "w": "",
  "attr": {
    "label": "Nhập điểm từ Excel",
    "icon-text": "mdi-microsoft-excel",
    ":header-format": 1,
    ":raw-format": false,
    "v-model": "dsDiemNhap",
    ":action": { "CALL": "xuLyDiemNhap" }
  }
}
```

```json
{
  "xuLyDiemNhap": {
    "FUN": "chuanHoaDiem",
    "IN": { "rows": "dsDiemNhap" },
    "OUT": "dsDiemDaChuan"
  }
}
```
</Tab>

</Tabs>

## Lỗi thường gặp

<Callout type="warn">
**Chỉ đọc sheet đầu tiên.** File nhiều sheet thì các sheet sau bị bỏ qua — báo người dùng gộp về
một sheet trước khi tải lên.
</Callout>

<Callout>
Muốn kiểm tra dữ liệu trước khi lưu, đổ thẳng kết quả vào một `f-table` tạm để người dùng xem
lại, rồi mới có nút "Xác nhận lưu" gọi API riêng — đừng lưu thẳng ngay khi đọc xong.
</Callout>

## Prompt cho AI

<AiPrompt>
Tôi đang viết một module FUI V2 (Vue 2 + Vuetify 2, cấu hình bằng JSON gồm 4 khối `data`,
`watch`, `controls`, `set`).

Hãy thêm cho tôi chức năng nhập [ĐỐI TƯỢNG] hàng loạt từ Excel: đọc file, xem trước trong bảng,
rồi mới lưu khi bấm xác nhận.

Yêu cầu bắt buộc khi viết JSON FUI:
- Dùng `f-excel-reader`, kết quả bind qua `v-model` vào một mảng state
- Đổ mảng đó vào `f-table` tạm để xem trước, không lưu thẳng ngay khi đọc xong
- Nút "Xác nhận lưu" riêng, gọi API lưu hàng loạt
- Không khai lại `elevation: "1"` và `color: "primary"` — FUI đã tự thêm
- Không tự thêm `class`/`style` để làm đẹp

Trả về `data[]` và `controls` liên quan.
</AiPrompt>
