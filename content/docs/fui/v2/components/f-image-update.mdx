`f-image-update` mở dialog chọn ảnh, cắt theo tỉ lệ cố định, rồi upload — dùng cho avatar, ảnh
đại diện, logo.

## Import bắt buộc

<Callout type="error">
Thiếu import thì component không tồn tại.

```text
/include/vue-advanced-cropper/index.umd.js
/include/vue-advanced-cropper/style.css
```
</Callout>

## Cách dùng

<Tabs items={['Avatar vuông (demo)', 'Ảnh bìa tỉ lệ 16:9']}>

<Tab value="Avatar vuông (demo)">
```json
{
  "el": "f-image-update",
  "w": "",
  "attr": {
    "v-model": "form.anhDaiDien",
    "label": "Ảnh đại diện",
    "api-upload": "/api/upload/avatar",
    ":dialog-width": 500,
    ":dialog-height": 400
  }
}
```

Mặc định `croperAttr` đã ép `aspectRatio: 1` (hình vuông) — hợp cho avatar.
</Tab>

<Tab value="Ảnh bìa tỉ lệ 16:9">
```json
{
  "el": "f-image-update",
  "w": "",
  "attr": {
    "v-model": "form.anhBia",
    "label": "Ảnh bìa",
    "api-upload": "/api/upload/cover",
    ":croper-attr": { "stencil-props": { "aspectRatio": 1.777 } },
    ":dialog-width": 700,
    ":dialog-height": 500
  }
}
```
</Tab>

</Tabs>

## Lỗi thường gặp

<Callout type="warn">
**`apiUpload` phải trả về đúng cấu trúc mà `update` mong đợi** — component đọc field ảnh từ
response để cập nhật `v-model`. Kiểm tra lại field trả về của SP nếu ảnh không hiện sau khi
upload.
</Callout>

<Callout>
Cần crop tỉ lệ khác vuông (banner, ảnh bìa) thì luôn khai `:croper-attr.stencil-props.aspectRatio`
— bỏ qua thì mặc định ép vuông.
</Callout>
