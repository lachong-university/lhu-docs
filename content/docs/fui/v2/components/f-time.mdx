Cùng cơ chế với [`f-date`](/docs/fui/v2/components/f-date), dành cho giờ. Gõ trực tiếp theo mask
hoặc bấm icon để mở picker.

## Props

<TypeTable
  type={{
    value: { description: "Giá trị giờ, định dạng HH:mm. Dùng qua v-model.", type: "String" },
    label: { description: "Nhãn của ô nhập.", type: "String" },
    required: {
      description: "Bắt buộc nhập.",
      type: "Boolean",
      default: "true",
    },

      description: "Đặt sẵn giờ tương đối so với hiện tại, tính bằng phút. 30 = sau 30 phút.",

    },
  }}
/>

**Event**: `input` — phát ra `HH:mm`, hoặc `null` khi ô trống.

### Default FUI tự thêm

```json
{ ":hide-details": true, ":outlined": true, ":dense": true }
```

```json
{
  "el": "f-time",
  "w": 4,
  "attr": {
    "v-model": "form.gioBatDau",
    "label": "Giờ bắt đầu (sau 30 phút)",
    ":required": false,
    ":time-add": 30
  }
}
```
</Tab>

## Lỗi thường gặp

<Callout type="warn">
**`required` mặc định là `true`**, giống `f-date`. Ô không bắt buộc thì khai rõ
`":required": false`.
</Callout>

<Callout type="warn">
**Không khai `:required` thì `:rules` bị xoá.** `":required": false` là "bỏ hẳn rule", không phải
"không validate". Runtime chạy `if (!c.attr[":required"]) delete c.attr[":rules"]`.
</Callout>

## Component liên quan
