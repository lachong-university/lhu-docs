`f-editor` bọc CKEditor 5 — soạn thảo nội dung HTML ngay trong trang, không mở dialog.

## Import bắt buộc

<Callout type="error">
Thiếu import thì component không tồn tại.

```text
/include/ckeditor5/build/ckeditor.js
```
</Callout>

**Event**: `input` — nội dung HTML.

## Cách dùng

```json
{
  "el": "f-editor",
  "w": 12,
  "attr": {
    "v-model": "form.noiDungHtml",
    "imageapi": "/api/editor/upload",
    ":height": 360
  }
}
```

<Callout type="warn">
**`imageapi` mặc định trỏ về `https://fap.vn`** — gần như chắc chắn không phải endpoint bạn
muốn. Luôn khai rõ `imageapi` trỏ về API upload của project mình.
</Callout>

## Lỗi thường gặp

<Callout type="warn">
Nội dung là **HTML thô** — hiển thị lại ở nơi khác (ví dụ trong `f-table`) phải dùng renderer
`t-html`, không phải `t-label`, nếu không sẽ hiện nguyên thẻ HTML thay vì render.
</Callout>
