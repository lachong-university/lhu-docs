Cùng CKEditor 5 với [`f-editor`](/docs/fui/v2/components/f-editor), nhưng mở trong một dialog
thay vì soạn thảo tại chỗ. Hợp cho nội dung phụ, không chiếm chỗ trên form chính.

## Import bắt buộc

<Callout type="error">
Thiếu import thì component không tồn tại.

```text
/include/ckeditor5/build/ckeditor.js
```
</Callout>

<Callout type="warn">
**`value` là một object có hình dạng cố định**, không phải chuỗi HTML như `f-editor`. Khai state
ban đầu đúng dạng `{ open: false, text: '' }` trong `data[]`.
</Callout>

## Cách dùng

```json
{
  "data": [
    { "editorState": { "open": false, "text": "" } }
  ],
  "controls": [
    { "el": "f-button", "attr": {
        "label": "Soạn ghi chú", ":checkvalid": false,
        ":action": { "editorState.open": true } } },

    { "el": "f-editor-dialog", "attr": {
        ":value": "editorState",
        "label": "Nội dung ghi chú",
        ":width": 900,
        "imageapi": "/api/editor/upload" } }
  ]
}
```

Nội dung sau khi bấm OK nằm ở `editorState.text` — đọc field đó khi lưu.

## Lỗi thường gặp

<Callout type="warn">
**`imageapi` cũng nên khai rõ**, cùng lý do như `f-editor` — đừng để mặc định.
</Callout>
