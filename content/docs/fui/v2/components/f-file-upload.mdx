`f-file-upload` bọc Plupload: bấm nút, chọn file, tự động tải lên ngay, có dialog tiến trình
sẵn.

## Import bắt buộc

<Callout type="error">
Thiếu import thì component không tồn tại.

```text
/include/plupload-2.3.7/plupload.full.min.js
```
</Callout>

## Cách dùng

<Tabs items={['Tối giản (demo)', 'Giới hạn loại file', 'Xử lý sau khi upload']}>

<Tab value="Tối giản (demo)">
```json
{
  "el": "f-file-upload",
  "w": "",
  "attr": {
    "label": "Tải tệp lên",
    "url": "/api/upload/file",
    "v-on:input": "CALL(vueData.xuLyKetQuaUpload, { item: $event })"
  }
}
```
</Tab>

<Tab value="Giới hạn loại file">
```json
{
  "el": "f-file-upload",
  "w": "",
  "attr": {
    "label": "Tải PDF",
    "url": "/api/upload/pdf",
    ":filters": {
      "max_file_size": "20mb",
      "mime_types": [{ "title": "PDF", "extensions": "pdf" }]
    }
  }
}
```
</Tab>

<Tab value="Xử lý sau khi upload">
```json
{
  "el": "f-file-upload",
  "w": "",
  "attr": {
    "label": "Tải ảnh minh chứng",
    "url": "/api/upload/file",
    ":resize": { "width": 1200, "height": 1200, "quality": 80 },
    ":onclose": { "CALL": "apiDanhSach" }
  }
}
```

`onclose` chạy khi dialog tiến trình đóng lại — dùng để tải lại danh sách sau khi thêm file.
</Tab>

</Tabs>

## Lỗi thường gặp

<Callout type="warn">
**`resize` chỉ tác động lên file ảnh.** File PDF, Word… đi qua nguyên vẹn, không bị resize.
</Callout>

<Callout type="warn">
**`filters.mime_types` không tự động khớp phần mở rộng.** Khai đúng `extensions` (không có dấu
chấm, ví dụ `"pdf"` chứ không phải `".pdf"`), nếu không dialog chọn file sẽ không lọc đúng.
</Callout>
