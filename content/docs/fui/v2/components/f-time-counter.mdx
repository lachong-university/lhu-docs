Không phải ô nhập — `f-time-counter` chỉ hiển thị. Ba chế độ: đếm ngược đầy đủ, đếm ngược rút
gọn, hoặc đồng hồ thời gian thực.

## Cách dùng

<Tabs items={['Đếm ngược đầy đủ (demo)', 'Đồng hồ thời gian thực', 'Đếm ngược đến hạn']}>

<Tab value="Đếm ngược đầy đủ (demo)">
```json
{
  "el": "f-time-counter",
  "w": 6,
  "attr": {
    ":value": 3600,
    ":type": 0,
    ":format": {
      "label": "Còn lại: ",
      "day": " ngày", "hour": " giờ", "minute": " phút", "second": " giây"
    }
  }
}
```
</Tab>

<Tab value="Đồng hồ thời gian thực">
```json
{ "el": "f-time-counter", "w": 4, "attr": { ":type": 2 } }
```
</Tab>

<Tab value="Đếm ngược đến hạn">
Đếm tới một mốc thời gian tuyệt đối thay vì số giây tương đối — truyền chuỗi datetime:

```json
{
  "el": "f-time-counter",
  "w": 6,
  "attr": {
    ":value": "'2026-12-31 23:59:59'",
    ":type": 0,
    "v-on:time-end": "CALL(vueData.hetHan)"
  }
}
```
</Tab>

</Tabs>

## Lỗi thường gặp

<Callout type="warn">
**`time-end` chỉ bắn khi bộ đếm chạm 0** — không bắn khi component bị unmount hay `value` đổi
giữa chừng. Cần dọn dẹp khi rời trang thì tự xử lý ở nơi khác.
</Callout>

<Callout>
Muốn phát âm thanh hoặc mở dialog khi hết giờ, bắt `v-on:time-end` như ví dụ "Đếm ngược đến hạn"
ở trên.
</Callout>
