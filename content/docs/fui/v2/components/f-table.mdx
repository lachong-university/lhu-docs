Dùng `f-table` cho **mọi bảng dữ liệu**, cả CRUD lẫn chỉ xem. Không dùng `v-data-table` trực tiếp
— `f-table` đã có sẵn sắp xếp, tìm kiếm, xuất Excel, CRUD qua dialog và điều khiển trong ô.

Bảng chỉ đọc = `f-table` **không khai** `:update-api`.

### Default FUI tự thêm

```json
{
  ":dense": true,           ":show-search": true,
  ":fixed-header": true,    ":items-per-page": 50,
  ":hide-default-footer": true,  ":return-object": true,
  ":excel": false,          ":allow-hover": false,

```

**Event**: `input` (dòng được chọn) · `click:row` · `mouseover:row` · `mouseleave:row`

## Chiều cao

`f-table` tự **đo vị trí thật** của bảng trên trang (`getBoundingClientRect().top`) rồi tính
chiều cao còn lại — không cần tự cộng trừ chiều cao header/toolbar phía trên.

| `:height` | Hành vi |
|---|---|
| *(bỏ trống)* | Tự giãn theo số dòng — hợp cho bảng ngắn/lookup. Bảng chính của trang thì **sai**, cả trang sẽ cuộn |
| `<= 0` | Fill tới đáy màn hình, chừa `abs(height)` px — **chuẩn cho bảng chính**, dùng `":height": -16` |
| `> 0` | px cố định — dùng khi bảng nằm **trong dialog**, ví dụ `":height": 360` |

Tự cập nhật khi resize cửa sổ và khi `items` đổi. Cùng ba chế độ này áp dụng cho
[`f-sheet`](/docs/fui/v2/components/f-sheet#chiều-cao).

<Callout type="warn">
**Pattern cũ `":height": "$( window ).height()-285"` không dùng nữa.** Nó bắt tự đoán tổng
chiều cao mọi thứ phía trên bảng — sai một chút là bảng hụt hoặc tràn. Thấy pattern này trong
module cũ thì thay bằng `":height": -16`.
</Callout>

## Định nghĩa cột

Mỗi phần tử của `headers`:

| Khoá | Tác dụng |
|---|---|
| `text` | Nhãn cột |
| `value` | Tên field trong dữ liệu |
| `align` | `left` (mặc định) · `center` · `right` |
| `width` | `"200px"` · `"10%"` |
| `divider` | `true` = kẻ dọc sau cột này |
| `el` | Renderer trong ô: một trong các `t-*` |
| `attr` | Props cho `el` |
| `innerHTML` | Nội dung — dùng với `v-icon`, `v-chip-group` |

Cột có `el` thì `f-table` **tự sinh slot** và tự truyền vào `item`, `index`, cùng
`v-model="item['<value>']"`.

### Renderer trong ô

| `el` | Hiển thị |
|---|---|
| `t-label` | Chữ, không xuống dòng |
| `t-html` | HTML thô |
| `t-num` | Số căn phải, phân cách nghìn. `attr.format` nhận chuỗi numeral |
| `t-time` | Ngày giờ. `attr.format` mặc định `DD/MM/YYYY` |
| `t-boolean` | Icon check/close theo giá trị true-false |
| `t-check` | Checkbox bật tắt, có `:action` |
| `t-text` | Ô nhập text ngay trong bảng |
| `t-select` · `t-combobox` | Dropdown ngay trong bảng |
| `t-menu` | Menu ngữ cảnh |
| `t-link` | Đường dẫn |
| `t-button` | Nút bấm có `:action` |

### Header tự dựng

Bỏ hẳn `:headers` thì bảng tự dựng cột từ dòng đầu tiên của `items`: mỗi key thành một cột,
key có giá trị số tự gắn `t-num`, và headers được dựng lại mỗi khi `items` đổi.

```json
{ "el": "f-table", "w": 12, "attr": { "label": "Kết quả", ":items": "dsKetQua" } }
```

Hợp khi API đã alias tên cột đẹp sẵn. **Phải khai `:headers` tường minh** khi cần: nhãn khác tên
field, ẩn bớt cột, dùng renderer `t-*`, đặt width/align, hoặc dữ liệu có field kỹ thuật không nên
hiện.

Ba điểm đáng chú ý:

- Cột **`"value": "ctrl-update"`** kích hoạt slot sửa/xoá dựng sẵn. Không có cột này thì không
  có nút thao tác nào.
- `:update-form` là mảng **Control Object** — cùng schema `el`/`attr` như `controls`. Bên trong,
  `v-model` trỏ thẳng vào field của dòng.
- `"jsonObj": "$row"` truyền cả object dòng thay vì liệt kê từng field.

Bỏ bớt khoá nào trong `:update-api` thì mất chức năng tương ứng — chỉ có `edit` thì không hiện
nút thêm mới.

## Tổng cột

Có **hai dạng**, render khác hẳn nhau.

<Tabs items={['Object → hàng tổng trong bảng', 'String → dòng text dưới bảng']}>

<Tab value="Object → hàng tổng trong bảng">
```json
":sum-format": { "DangKy": "0,0", "NhapHoc": "0,0", "HocPhi": "0,0.0" }
```

Key là `value` của cột, value là chuỗi format numeral riêng cho cột đó. Render thành một `<tr>`
cuối thân bảng, **thẳng hàng với cột**, cuộn cùng bảng.

Là object → khai với prefix `:`.
</Tab>

<Tab value="String → dòng text dưới bảng">
```json
"sum-format": "Tổng đăng ký: [[DangKy]] | Nhập học: [[NhapHoc]]"
```

`[[Field]]` được thay bằng tổng của cột đó, format cố định `0,0`. Ra **một dòng chữ** căn phải
dưới bảng, không thẳng cột.

Là chuỗi tĩnh → khai **không** có prefix `:`.
</Tab>

</Tabs>

<Callout type="warn">
**Đừng tự dựng hàng tổng.** Không push dòng "Tổng" vào `items`, không tự viết template
`body.append` — dùng `sum-format`.
</Callout>

## Lỗi thường gặp

<Callout type="warn">
**`item-key` bắt buộc khi dùng chọn dòng hoặc CRUD.** Thiếu nó thì việc chọn dòng hoạt động
thất thường và CRUD không xác định được dòng nào đang sửa.
</Callout>

<Callout type="warn">
**`:hide-default-footer` mặc định là `true`.** Bảng nhiều dữ liệu sẽ không có thanh phân trang.
Hoặc đặt `":items-per-page": -1` để hiện hết, hoặc `":hide-default-footer": false` để bật lại
phân trang.
</Callout>

<Callout type="warn">
**Đừng dùng `f-button` + `f-dialog` để làm form thêm mới** — không ổn định trong FUI V2. Dùng
`ctrl-update` như trên. Cần dialog có logic riêng thì dựng `v-dialog` thủ công trong container
`"prop": "hidden-container"`.
</Callout>
