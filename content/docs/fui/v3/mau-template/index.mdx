## Khung mẫu

```json
{
  "data": [
    { "dsItem": [] },
    { "apiDanhSach": { "API": "/api/item/list", "OUT": "dsItem" } },
    { "CALL": "apiDanhSach" }
  ],
  "watch": {},
  "controls": [
    {
      "prop": "fluid grid-list-md",
      "rows": [
        {
          "prop": "row",
          "cols": [
            {
              "el": "f-table",
              "w": 12,
              "attr": {
                "label": "Danh sách",
                ":items": "dsItem",
                "item-key": "ID"
              }
            }
          ]
        }
      ]
    }
  ],
  "set": {}
}
```

`f-table` tự dựng cột nếu bạn không khai `:headers`.

## Nguyên tắc chung

- `data[]`: state → action có tên → action tự chạy.
- Mỗi filter nên có `watch` gọi API.
- Chuỗi không có dấu cách phải bọc backtick để không bị eval.
- Ô lọc phải khai `":required": false`.
- Chia cột bằng `w`, không dùng `style` để thay thế layout.

## Khi nào tách component

Nếu module quá dài, tách phần UI sang `uc-*.vue` và giữ JSON chỉ còn dữ liệu,
API và điều kiện hiển thị.
